# Theme mockups (480×360)

Static mockups of the five visual directions in `docs/PRODUCT.md` §6, each with the same three widgets
(clock, system monitor, now playing) and the same fictional sample data. `overview.png` shows all of them.

Regenerate: `python gen.py` (needs Google Chrome; fonts load from Google Fonts: Inter, Doto, VT323,
IBM Plex Sans Condensed, EB Garamond, Cormorant SC — all SIL OFL). Seven-segment digits are drawn as SVG.
These are design studies, not the widget runtime.
