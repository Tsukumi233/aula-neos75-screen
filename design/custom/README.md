# Your own pages

Every `.html` file here is a page of the screen library (next to `design/neos` and `design/widgets`), so
`../neos/neos.css`, `../widgets/data.js` and `../official/jpg/` work the same way. Start one with
`sdk/.venv/Scripts/neos75ctl new NAME --title "标题"`, check it with `neos75ctl check NAME -o shot.png`,
and add it with `neos75ctl pages add NAME` (or in the desktop app). How to write one:
`.claude/skills/neos75-screen/`.
